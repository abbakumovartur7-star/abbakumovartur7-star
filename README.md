# Artur 

Создаю лендинги, калькуляторы, трекеры и чат-ботов для ВКонтакте с помощью ИИ. Моё направление — задачи малого бизнеса.

## Чем могу помочь

- Создание лендингов.
- Разработка калькуляторов стоимости.
- Создание трекеров для учёта и сохранения данных.
- Разработка чат-ботов для ВКонтакте.

## Учебные проекты

Все проекты ниже выполнены в рамках обучения.

- **Матчдень** — трекер избранных матчей разных видов спорта. Позволяет указывать дату и время матча, записывать предполагаемый результат, добавлять комментарии и заметки, сохранять данные.
- **Лендинг международного трейдинг-клуба** — знакомит посетителя с клубом и его предложениями, позволяет оставить заявку для обратной связи.
- **Калькулятор стоимости перегородок** — позволяет собрать корзину компонентов, рассчитать стоимость, сохранить выбранный заказ и обновлять данные онлайн.

## Как я работаю

Самостоятельно готовлю большую часть промптов, определяю дизайн и последовательность задач, проверяю и тестирую результат. Техническую реализацию выполняю с помощью ИИ.

Использую **Codex** и **OpenCode**.
